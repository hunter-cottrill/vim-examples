# Module 8 · Your own app

## Self-paced

**Say:** "You've built each piece by hand. Now let's see how fast a whole app comes together — and you'll know what to look for in it."

Remind them of what they said in Module 0. In a **new, empty folder** — not inside the course — have them start the build skill and describe that app. In Claude Code:

    /vim-app-builder:new-vim-app

In other agents: ask it to build a new Vim Connect app.

**When it's built, find the building blocks together**, one question at a time:
- Where does it connect? (Module 1)
- Which moments does it react to? (Module 3)
- How does it know who's on screen — and when they leave? (Module 4)
- What does it read, and does it cope with missing data? (Module 5)
- Does it write back with permission? (Module 6)

If anything's missing or wrong, that's the lesson: they can see it now, and fix it.

**Takeaway:** An agent can build a Vim app quickly. Knowing the building blocks is what lets you trust it.

## In the Mock EHR — building a prototype

Day 2 of a workshop. The team is building a prototype of one of their own applications, with the facilitator's help.

1. **Start from the closest template.** The facilitator will help pick it. Don't run `/vim-app-builder:new-vim-app` unless the facilitator says to.
2. **Find the building blocks first**, using the questions above. It's code they're about to change.
3. **Shape it to their prototype** in small steps, saying which building block each change touches.
4. **Try each step in the Mock EHR** as you go.
